Next.js 使用 `App` 组件来初始化页面。你可以覆盖它并控制页面初始化，以便：

- 在页面切换之间创建共享布局
- 向页面注入额外数据
- [添加全局 CSS](/docs/app/getting-started/css)

## 用法

要覆盖默认的 `App`，请创建 `pages/_app` 文件，如下所示：

```tsx filename="pages/_app.tsx" switcher
import type { AppProps } from 'next/app'

export default function MyApp({ Component, pageProps }: AppProps) {
  return <Component {...pageProps} />
}
```

```jsx filename="pages/_app.jsx" switcher
export default function MyApp({ Component, pageProps }) {
  return <Component {...pageProps} />
}
```

`Component` prop 是当前活动的 `page`，因此每当你在路由之间导航时，`Component` 将更改为新的 `page`。因此，你发送给 `Component` 的任何 props 都将被 `page` 接收。

`pageProps` 是一个对象，包含通过我们的[数据获取方法](/docs/pages/building-your-application/data-fetching)为你的页面预加载的初始 props，否则它是一个空对象。

> **值得注意的是**：
>
> - 如果你的应用正在运行并且你添加了自定义 `App`，则需要重启开发服务器。仅在 `pages/_app.js` 之前不存在时才需要。
> - `App` 不支持 Next.js [数据获取方法](/docs/pages/building-your-application/data-fetching)，如 [`getStaticProps`](/docs/pages/building-your-application/data-fetching/get-static-props) 或 [`getServerSideProps`](/docs/pages/building-your-application/data-fetching/get-server-side-props)。

## 在 `App` 中使用 `getInitialProps`

在 `App` 中使用 [`getInitialProps`](/docs/pages/api-reference/functions/get-initial-props) 将禁用没有 [`getStaticProps`](/docs/pages/building-your-application/data-fetching/get-static-props) 的页面的[自动静态优化](/docs/pages/building-your-application/rendering/automatic-static-optimization)。

**我们不推荐使用这种模式。** 相反，请考虑[逐步采用](/docs/app/guides/migrating/app-router-migration) App Router，它可以让你更轻松地为页面和布局获取数据。

```tsx filename="pages/_app.tsx" switcher
import App, { AppContext, AppInitialProps, AppProps } from 'next/app'

type AppOwnProps = { example: string }

export default function MyApp({
  Component,
  pageProps,
  example,
}: AppProps & AppOwnProps) {
  return (
    <>
      <p>Data: {example}</p>
      <Component {...pageProps} />
    </>
  )
}

MyApp.getInitialProps = async (
  context: AppContext
): Promise<AppOwnProps & AppInitialProps> => {
  const ctx = await App.getInitialProps(context)

  return { ...ctx, example: 'data' }
}
```

```jsx filename="pages/_app.jsx" switcher
import App from 'next/app'

export default function MyApp({ Component, pageProps, example }) {
  return (
    <>
      <p>Data: {example}</p>
      <Component {...pageProps} />
    </>
  )
}

MyApp.getInitialProps = async (context) => {
  const ctx = await App.getInitialProps(context)

  return { ...ctx, example: 'data' }
}
```
