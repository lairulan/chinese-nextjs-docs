---
title: How to upgrade to version 10
nav_title: Version 10
description: 将你的 Next.js 应用从版本 9 升级到版本 10。
slug: /docs/pages/guides/upgrading/version-10
---

版本 9 和版本 10 之间没有破坏性变更。

要升级到版本 10，请运行以下命令：

```bash filename="Terminal"
npm i next@10
```

```bash filename="Terminal"
yarn add next@10
```

```bash filename="Terminal"
pnpm up next@10
```

```bash filename="Terminal"
bun add next@10
```

> **值得注意的是**： 如果你正在使用 TypeScript，请确保你同时升级 `@types/react` 和 `@types/react-dom` 到对应的版本。
