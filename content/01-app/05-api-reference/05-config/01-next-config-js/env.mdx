</PagesOnly>

要在 JavaScript 包中添加环境变量，请打开 `next.config.js` 并添加 `env` 配置：

```js filename="next.config.js"
module.exports = {
  env: {
    customKey: "my-value",
  },
};
```

现在你可以在代码中访问 `process.env.customKey`。例如：

```jsx
function Page() {
  return <h1>The value of customKey is: {process.env.customKey}</h1>;
}

export default Page;
```

Next.js 将在构建时将 `process.env.customKey` 替换为 `'my-value'`。由于 webpack [DefinePlugin](https://webpack.js.org/plugins/define-plugin/) 的特性，尝试解构 `process.env` 变量将无法工作。

例如，以下行：

```jsx
return <h1>The value of customKey is: {process.env.customKey}</h1>;
```

最终将变为：

```jsx
return <h1>The value of customKey is: {"my-value"}</h1>;
```
