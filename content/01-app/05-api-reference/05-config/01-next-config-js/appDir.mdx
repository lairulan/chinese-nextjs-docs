> **值得注意的是**：从 Next.js 13.4 开始，此选项**不再**需要。App Router 现已稳定。

App Router（[`app` 目录](/docs/app)）支持[布局](/docs/app/api-reference/file-conventions/layout)、[Server Components](/docs/app/getting-started/server-and-client-components)、[流式传输](/docs/app/api-reference/file-conventions/loading)和[同位数据获取](/docs/app/getting-started/fetching-data)。

使用 `app` 目录将自动启用 [React Strict Mode](https://react.dev/reference/react/StrictMode)。了解如何[逐步采用 `app`](/docs/app/guides/migrating/app-router-migration#migrating-from-pages-to-app)。
