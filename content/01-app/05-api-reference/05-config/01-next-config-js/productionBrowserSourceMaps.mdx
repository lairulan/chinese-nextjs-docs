源映射在开发过程中默认启用。在生产构建期间，为了防止客户端泄露源代码，它们默认是禁用的，除非你通过配置标志明确选择加入。

Next.js 提供了一个配置标志，你可以在生产构建期间启用浏览器源映射生成：

```js filename="next.config.js"
module.exports = {
  productionBrowserSourceMaps: true,
};
```

当 `productionBrowserSourceMaps` 选项启用时，源映射将输出在与 JavaScript 文件相同的目录中。Next.js 会自动在请求时提供这些文件。

- 添加源映射会增加 `next build` 时间
- 增加 `next build` 期间的内存使用
