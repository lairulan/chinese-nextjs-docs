你可以指定一个名称，用于自定义构建目录，以替代默认的 `.next` 目录。

打开 `next.config.js` 并添加 `distDir` 配置：

```js filename="next.config.js"
module.exports = {
  distDir: "build",
};
```

现在，如果你运行 `next build`，Next.js 将使用 `build` 目录，而不是默认的 `.next` 文件夹。

> `distDir` **不应该**离开你的项目目录。例如，`../build` 是一个**无效**的目录。
