> **注意**：此选项已被标记为稳定版本，因此你应该使用 `typedRoutes` 而不是 `experimental.typedRoutes`。

支持[静态类型链接](/docs/app/api-reference/config/typescript#statically-typed-links)。此功能需要在你的项目中使用 TypeScript。

```js filename="next.config.js"
/** @type {import('next').NextConfig} */
const nextConfig = {
  typedRoutes: true,
}

module.exports = nextConfig
```
