**forbidden** 文件用于在身份验证期间调用 [`forbidden`](/docs/app/api-reference/functions/forbidden) 函数时渲染 UI。除了允许你自定义 UI 外，Next.js 还将返回 `403` 状态码。

```tsx filename="app/forbidden.tsx" switcher
import Link from 'next/link'

export default function Forbidden() {
  return (
    <div>
      <h2>Forbidden</h2>
      <p>You are not authorized to access this resource.</p>
      <Link href="/">Return Home</Link>
    </div>
  )
}
```

```jsx filename="app/forbidden.jsx" switcher

```

## 参考

### Props

`forbidden.js` 组件不接受任何 props。
