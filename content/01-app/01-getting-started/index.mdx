欢迎来到 Next.js 文档!

这个**入门指南**部分将帮助你创建第一个 Next.js 应用程序,并学习你在每个项目中都会用到的核心功能。

## 前置知识

我们的文档假设你对 Web 开发有一定的了解。在开始之前,如果你熟悉以下内容会很有帮助:

- HTML
- CSS
- JavaScript
- React

如果你是 React 新手或需要复习,我们建议从[React 基础课程](/learn/react-foundations)开始,以及[Next.js 基础课程](/learn/dashboard-app),它会带你在学习的同时构建一个应用程序。
